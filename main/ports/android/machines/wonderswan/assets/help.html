cMESYS WonderSwan

Bandai WonderSwan / Color (Bandai, 1999) con el núcleo del driver de consola de cMESYS, migrado del emulador dsp-cpp: el mismo código que el de escritorio, la web y las placas.

Cartucho

Menú → Abrir cartucho: un fichero .ws, .wsc, .pc2 (o dentro de un .zip). Sacar cartucho lo expulsa y Reset reinicia la consola.

Mandos

Pantallala cruceta y los botones táctiles: Cruceta, A, B; START = START
Mando físicocruceta, A / B / X / Y, START y SELECT
Teclado físicocursores; las teclas de la consola; ENTER = START

Teclado de la consola

W A S D: Y1-Y4

Ajustes

Escala de la imagen, el mando en pantalla y abrir el último cartucho al empezar.

Créditos

cMESYS: Chusogar. dsp-cpp: Chusogar, a partir del emulador DSP de Leniad.
