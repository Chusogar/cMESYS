cMESYS Super Cassette Vision

Epoch Super Cassette Vision (Epoch, 1984) con el núcleo del driver de consola de cMESYS, migrado del emulador dsp-cpp: el mismo código que el de escritorio, la web y las placas.

Cartucho

Menú → Abrir cartucho: un fichero .bin, .0, .rom (o dentro de un .zip). Sacar cartucho lo expulsa y Reset reinicia la consola. Necesita la BIOS del SCV (upd7801g.s01 + epochtv.chr, o ambas en un fichero de 5 KB): va dentro de la app si se compiló con ella (tools/regen.sh scv); las BIOS no se distribuyen con cMESYS.

Mandos

Pantallala cruceta y los botones táctiles: Cruceta, 1, 2; START = PAUSE
Mando físicocruceta, A / B / X / Y, START y SELECT
Teclado físicocursores; las teclas de la consola; ENTER = START

Teclado de la consola

0-9: the keypad, Q: CL, W: EN, P: pause

Ajustes

Escala de la imagen, el mando en pantalla y abrir el último cartucho al empezar.

Créditos

cMESYS: Chusogar. dsp-cpp: Chusogar, a partir del emulador DSP de Leniad.
