cMESYS PC Engine

NEC PC Engine (NEC / Hudson, 1987) con el núcleo del driver de consola de cMESYS, migrado del emulador dsp-cpp: el mismo código que el de escritorio, la web y las placas.

HuCard

Menú → Abrir hucard: un fichero .pce, .bin (o dentro de un .zip). Sacar hucard lo expulsa y Reset reinicia la consola.

Mandos

Pantallala cruceta y los botones táctiles: Cruceta, I, II; START = RUN; SELECT = SELECT
Mando físicocruceta, A / B / X / Y, START y SELECT
Teclado físicocursores; Z X C V = botones 1 a 4, ENTER = START

Ajustes

Escala de la imagen, el mando en pantalla y abrir el último hucard al empezar.

Créditos

cMESYS: Chusogar. dsp-cpp: Chusogar, a partir del emulador DSP de Leniad.
