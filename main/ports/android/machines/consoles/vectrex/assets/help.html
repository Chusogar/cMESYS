cMESYS Vectrex

Vectrex (GCE, 1982) con el núcleo del driver de consola de cMESYS, migrado del emulador dsp-cpp: el mismo código que el de escritorio, la web y las placas.

Cartucho

Menú → Abrir cartucho: un fichero .vec, .bin, .gam (o dentro de un .zip). Sacar cartucho lo expulsa y Reset reinicia la consola. Necesita la BIOS del Vectrex (exec_rom.bin, 8 KB; sin ella, ábrela como cartucho y juega a Mine Storm): va dentro de la app si se compiló con ella (tools/regen.sh vectrex); las BIOS no se distribuyen con cMESYS.

Mandos

Pantallala cruceta y los botones táctiles: Cruceta, 1, 2, 3, 4
Mando físicocruceta, A / B / X / Y, START y SELECT
Teclado físicocursores; Z X C V = botones 1 a 4, ENTER = START

Ajustes

Escala de la imagen, el mando en pantalla y abrir el último cartucho al empezar.

Créditos

cMESYS: Chusogar. dsp-cpp: Chusogar, a partir del emulador DSP de Leniad.
